# Security Policy

If you find a security problem in Macin (for example a way to delete files without confirmation, or a way for the AI assistant to run commands), please report it privately.

Use GitHub's **Report a vulnerability** button on the Security tab of this repository, or email naimur.rahman103@gmail.com.

Please include steps to reproduce. You will get an answer as soon as possible, and the fix will be released before details are made public.
