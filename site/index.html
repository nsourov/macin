FAQ

Questions, answered.

Is Macin free?

Yes. Macin is free and open source under the MIT license.

Which Macs are supported?

Macs running macOS 14 Sonoma or later. Apple's on-device AI needs macOS 26 with Apple Intelligence; otherwise you can connect your own model, or use Macin without AI.

Is it safe to clean what Macin suggests?

Macin only suggests items from known categories like caches, logs and developer files, and it explains each one. You review everything, and items go to the Trash so you can restore them.

Why does free space differ from other apps?

Macin shows the same number as Finder, which includes "purgeable" space macOS can free by itself. Tools like df only count space that is completely empty right now.

Can the AI change or delete things on my Mac?

No. It can only use a fixed list of read-only checks. It can't run its own commands, change settings or delete anything.

Does Macin download an AI model?

Never. It uses Apple's model built into macOS, or a model you already run, like Ollama or LM Studio.
